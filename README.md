# Penetration_Testing_Report
**Footprinting & Network Scanning Phases**

This repository contains the practical documentation and professional report for **Week 2** of my Cybersecurity training program at Networkwalks.

## 📄 Overview
This project focuses on the foundational phases of a penetration test: **Reconnaissance & Footprinting** and **Network Scanning & Discovery**. It documents hands-on terminal workflows, command executions, target scoping, and structured reporting.

## 🛠️ Tools & Technologies Used
The following Kali Linux tools and network utilities were utilized during this lab:
* **Whois** – Domain ownership and registration reconnaissance.
* **WhatWeb** – Web technology and Content Management System (CMS) fingerprinting.
* **Nslookup** – DNS record lookup and name resolution.
* **DNSRecon** – Automated DNS enumeration and zone transfer checks.
* **Nmap / Zenmap** – Port scanning, service version detection, and network mapping.

## 📋 Phases Covered
1. **Phase 1: Reconnaissance & Footprinting** — Gathering passive and active intelligence about target infrastructure and domain configurations.
2. **Phase 2: Scanning & Network Discovery** — Identifying live hosts, open ports, and running services across the target scope.
3. **Phase 3-5: In Progress** — Upcoming vulnerability assessment and exploitation phases.
